# Library Tycoon V2.5 | طور مدير المكتبة والتحديات الميدانية

هذا تحديث محلي مباشر لنسخة V2.3 أو V2.4 الأصلية، وليس لعبة مستقلة. يحتاج مجلد اللعبة المحلي الذي يضم Babylon.js والمجسمات والشعارات الأصلية. لا يتطلب حساب API أو اشتراكاً أو خدمة سحابية أثناء التشغيل.

## الجديد القابل للتجربة

1. **مهمة الكتاب المفقود داخل الخريطة**: ثلاثة علامات أرفف تظهر بإحداثيات القاعة الحقيقية، عند الضغط تختار الرف الصحيح. ثلاث محاولات وخلال 80 ثانية لعب، مكافأة افتراضية 105 وحدات ورضا +2 عند النجاح، انتظار 90 ثانية لعب قبل جولة ثانية. البحث على الخريطة تفاعل مع نقاط رفوف فوق المشهد، وليس تحريك شخصية اللاعب داخل القاعة.
2. **تحدي أسبوع الامتحانات**: يبدأ من طور المدير بعد المستوى 2 وتوظيف أمين واحد. لمدة 115 ثانية لعب تزيد أعداد الزوار وسرعة حضورهم. مطلوب خدمة 8 زوار ورضا لا يقل عن 70% عند النهاية، مكافأة 260 وحدة افتراضية. يُتاح بدء واحد لكل يوم لعبة، وتُحسب النتيجة مرة واحدة.
3. **حالات الزوار الخاصة**: أربعة أنواع، بحسب الخدمات المفتوحة: استعارة، طباعة، مطالعة، بحث. الحالة تولّد زائراً فعلياً في المحاكاة وتتحرك مع الزوار. زر الأولوية ينقله لمقدمة الطابور عند وصوله، ويخفض رضا بقية الزوار نقطة واحدة. عند إكمال الخدمة يحصل اللاعب على مكافأة إضافية، وعند المغادرة تنخفض السمعة.
4. **دوام الموظفين**: الموظف المكلف يظل بمكانه الثابت ويبدأ خدمة الزوار آلياً، ولا يدخل الخدمة الجديدة أثناء استراحة 22 ثانية. استراحته لا تحركه لمكان آخر. عامل النظافة يبقى يتنقل بين نقاط المنطقة المحددة حول مكتبه فقط. الزي الرسمي الكحلي والذهبي من V2.4 محفوظ في مشهدي Babylon وLegacy.
5. **السمعة الفعلية**: شريط التقييم 1–5 نجوم يعتمد على رضا الطلبة، النظافة، الخدمات المكتملة مقابل المغادرين، والانتظار. لا يعتمد على صرف المال والترقيات فقط.

يبقى مسار المهمات الثمانية، تصنيف الكتب، الأحداث الأربعة، الخدمات والترقيات، ونظام الحفظ الأصلي من V2.4.

## التشغيل على Windows

1. **شرط**: وجود V2.3 أو V2.4 معروفة البصمة على مجلدك الأصلي `D:\Projects\Library-Tycoon-V21\outputs\V22`. لا تشغّل هذا التحديث على V2.2 مباشرة، ولا تفكّ الحزمة فوق النسخة الأصلية.
2. فك ضغط الحزمة في مجلد مراجعة مستقل، وشغّل `APPLY_WINDOWS.cmd`، أو نفّذ `node apply_local.cjs "D:\Projects\Library-Tycoon-V21\outputs\V22"`.
3. المثبت يرفض أي مراجعة غير مطابقة لبصمة V2.3 أو V2.4، ثم يختبر الكود ويأخذ نسخة رجوع `V22_pre_V25_<date>` بجانب اللعبة قبل الاستبدال.
4. افتح اللعبة باستخدام `START_WINDOWS.bat` الأصلي واضغط `🏛️ مكتب مدير المكتبة`.
5. لاسترجاع النسخة السابقة، شغّل `RESTORE_WINDOWS.cmd` الموجود داخل مجلد نسخة الرجوع، بشرط عدم تعديل ملفات V2.5 بعد التركيب.

## الهوية والحقوق

- لا تحتوي هذه الحزمة أي صورة شعار مولّدة أو بديلة. لم نبدّل شعار المكتبة المركزية، ولا شعار الجامعة التكنولوجية، ولا تميمة الحارس الصغير.
- تبقى ملفات `assets/branding/`, `assets/guardian/`, `assets/models/`, `vendor/`, وبيانات اللعبة الموجودة في المتصفح دون مساس.
- الزي الجديد محاكاة مؤسسية، وليس بديلاً للشعار الأصلي.
- لا رفع إلى GitHub أو السيرفر، ولا روابط CDN، ولا API مدفوع.

## حدود الفحص

الاختبارات المحلية تفحص منطق المهمات والمكافآت والحفظ والتركيب والرجوع. المشهد ثلاثي الأبعاد كاملاً، لقطات الشاشة، ومجسمات GLB وحركات العظام ما زالت تحتاج اختباراً على Windows بالملفات الأصلية وبطاقة GPU. لا تُعتبر الحزمة لعبة مستقلة دون الأصول الأساسية.
