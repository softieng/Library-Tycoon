# Asset sources and provenance

## Included assets

- **Kenney Furniture Kit**, 18 standalone GLB models: bookcaseopen, bookcaseopenlow, bookcaseclosedwide, books, table, desk, chaircushion, chairdesk, chairrounded, laptop, computerscreen, pottedplant, plantsmall2, lamproundtable, bench, rugrectangle, trashcan, tablecoffee.
- **Kenney Mini Characters**, 4 standalone rigged animated GLB models: character-male-b, character-male-e, character-female-a, character-female-e. Each has source animation clips including walk, sit, idle.
- Original artists: **Kenney**. License: Creative Commons Zero 1.0 Universal, CC0-1.0.
- Source repository and actual files: https://github.com/Hidencod/tge-assets (`packs/furniture-kit/*.glb` and `packs/mini-characters/*.glb`)
- Original artist's packs: https://kenney.nl/assets/furniture-kit and https://kenney.nl/assets/mini-characters
- License confirmation: https://kenney.nl/support and repository README.
- Integrity: exact Git blob SHA matches were verified when copying each asset into `softieng/Library-Tycoon`.

- **Kenney Nature Kit**, 3 standalone GLB models: tree-detailed, plant-bushdetailed, flower-yellowb. All CC0-1.0, mirrored from `packs/nature-kit/*.glb` in the same source repository.

## Game engine

- Babylon.js engine and glTF loader: https://github.com/BabylonJS/Babylon.js , Apache-2.0.
- Code generated for this game (scene composition, materials, mission bindings, stage, UI) is not the Kenney assets.

## Institutional assets

Official UOT and Central Library logo images and their mascots are **NOT included** or recreated. Only reserved text slots exist. Adding official logos requires verified original master files and owner review.
