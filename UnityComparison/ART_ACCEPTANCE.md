# Unity art comparison acceptance criteria

1. A compiled, running Unity 6.3 scene, with an actual screenshot directly from Game view.
2. At least 15 manifest-verified GLBs loaded, and no missing assets or pink materials.
3. Camera rotation permanently fixed, pan/zoom work, room visibly readable at 1920x1080.
4. Correct scale/placement for furniture, no clipping between chairs, tables and characters.
5. Imported student animation actually plays; note any failed glTF clip import honestly.
6. Confirm service employee remains at assigned desk.
7. Click shelves in world: correct shelf completes mission, reward paid once on reload.
8. Mascot uses actual approved protected 8-legged pseudoscorpion anatomy and two pedipalps. The existing V3 model is **not accepted** without visual owner review.
9. Compare with approved concept reference **and** a Babylon V3 screenshot, naming quality differences rather than relying on a promotional rendering.
10. Measure FPS, load time, WebGL size and memory on target Windows GPU before approving migration.
11. No product/public-branch replacement, no deleting original assets, and no live deployment until explicit owner approval.

CI static GLB verification alone does not satisfy acceptance.
