## إنجاز هذه الدفعة (قابل للفحص من المستودع)
- `src/config/jabirHall.ts`: ثمانية رفوف كيمياء وهندسة ذات معرفات مستقرة، مواقع اقتراب، ست نقاط تفاعل، وثلاث مهام قصصية متسلسلة.
- `tests/unit/jabirHall.test.ts`: اختبارات سلامة التسمية والمواضع والروابط وتدرج المهام وعدم إعادة إكمالها.
- `featureFlags.ts` لم يتغير: `multiHall=false`. **لا توجد قاعة ثانية قابلة للعب حالياً**.
- أسماء الموضوعات والمجموعات مقترحة داخل اللعبة، ولا تمثل بيانات Koha أو التوزيع الفيزيائي الحقيقي.

## قرار هندسي
**استمرار React 19 + TypeScript + Babylon.js 9** هو الاختيار الرئيسي. لا نغير المحرك إلى Unity خلال هذه المرحلة.
المشهد الثاني يُبنى كـ scene root مستقل بنفس المضيف والكاميرا والمحرك وبنفس مسار الأصول. لا يُعاد إنشاء WebGL engine عند التنقل بين القاعات. يبقى تحريك الكاميرا pan/zoom فقط دون دوران.

## معايير القبول
- `npm ci`، `npm run typecheck`، `npm test`، `npm run assets:verify`، `npm run build` كلها ناجحة.
- فحص Chromium/WebGL يحاكي زيارة القاعة والعودة، الحركة والموظفين والمهمات الثلاث والدفع مرة واحدة، وإعادة تحميل الحفظ.
- لا يفقد اللاعب رصيده أو تقدمه عند التنقل أو إعادة التشغيل.
- وثّق FPS على RTX 3070 Ti في دقات 1920×1080 و1366×768، و1024×700 مع جودة منخفضة. لا تدّع بلوغ 60FPS قبل القياس.
- ست قاعات مذكورة بخارطة التطوير، لكن غير المبنية تبقى مقفلة.
- الأصول الرسمية محفوظة byte-identical، والشخصيات بزي مؤسسي.
- تشغيل من دون API مدفوعة، ومن دون بيانات حقيقية للمستعيرين.
- توثيق مصادر ورخص GLB والخامات قبل أي إضافة.
- اختبار الحفظ قبل/بعد ويكون الإصدار السابق قابل للاستعادة.
- الحصول على موافقة المستخدم على الصورة الفعلية للقاعة قبل الدمج أو النشر.
